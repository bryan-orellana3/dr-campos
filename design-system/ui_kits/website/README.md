# Website UI kit — Método 4C

Interactive landing site for the Dr. David Campos personal brand / Método 4C program. **No existing product was provided** — this surface was composed from the brand foundations (logo, backgrounds, tokens) as the canonical brand web surface, not a recreation.

- `index.html` — app shell (3 views: Inicio, El método, Aplicar; working form → Dialog → Toast)
- `sections.jsx` — SiteHeader, Hero, Stats, Pilares, Mentor, SiteFooter
- `screens.jsx` — screen compositions + App

All primitives come from the compiled design-system bundle; nothing is re-implemented.
