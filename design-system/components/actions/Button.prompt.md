Pill CTA button in the brand blues; use `primary` for the single main action per view.

```jsx
<Button variant="primary" size="lg" onClick={apply}>Aplicar al programa</Button>
<Button variant="secondary">Ver el método</Button>
```

Variants: `primary` (blue-500, darkens on hover), `secondary` (outlined royal), `ghost` (text-only), `onDark` (white pill for navy sections). Sizes sm/md/lg; `fullWidth`; `icon` accepts a Lucide node. Copy style: verbs, no exclamation marks.
